# Дизайн бағыттары — жұмыс файлдары

Бұл папка — интерфейстің дизайн жүйесін таңдауға арналған **бастапқы
көздер**. Өнімге кірмейді, `src/` ішіндегі кодқа әсер етпейді.

## Не үшін керек

Пайдаланушы «дизайн ыңғайсыз, көзді ауыртады» деген соң, ақау өлшеніп
анықталды (мәтіннің 60%-ы 11px-тен кіші, фон таза қара — контраст 17:1,
14 түрлі акцент түсі). Бір саты түзетілді, бірақ **тұтас жүйе** керек
болды. Бір бағытты болжаммен таңдап, 40 файлды қайта жазбас бұрын үш
нұсқа көзбен салыстыруға шығарылды.

## Файлдар

| Файл | Бағыт |
|---|---|
| `Main.dc.html` | **1 · Қараңғы+** — қазіргі теманың жетілдірілген нұсқасы |
| `Ashyq.dc.html` | **2 · Ашық** — құжатпен жұмыс істейтін қызметкерге |
| `Dataplatforma.dc.html` | **3 · Дата-платформа** — түс тек мәліметте |
| `canvas.json` | орналасуы + әр бағыттың артықшылығы мен шығыны |

Үшеуінде де БІРДЕЙ экран көрсетілген (навигация, «Аймақтық аналитика»,
ескерту жолағы, «Заңнамалық сәйкестік» карточкасы, сағаттық хронология
кестесі) — салыстыру әділ болу үшін.

Ортақ негіз: негізгі мәтін 14px, қосымша 12px, сандар моноширинді,
жол биіктігі 1.55, бір экранда екі акцент түсінен аспайды.

## ⚠️ Жол-жөнекей табылған ақау

`src/app/layout.tsx` **Geist** қаріпін жүктейді, ал
`src/app/globals.css`-тегі `body { font-family: Arial, ... }` оны басып
тастайды. Яғни сайт Arial-мен көрсетіліп тұр, ал жүктелген қаріп бекер
жүктеледі. Үш мокапта да нағыз Geist қолданылған.

Бұл бір жолдық түзету — бағыт таңдалғанда жасалады.

## Өзгерту тәртібі

Бұл файлдар — көз. Өзгерту керек болса, осыларды түзетіп, канвасты
қайта жинау керек. Жиналған нәтиже (~2 МБ, редактор payload-ы
қоса салынады) репозиторийге қосылмайды — `.gitignore` қара.
