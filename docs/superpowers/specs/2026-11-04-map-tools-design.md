# Карта құралдары: қызметкер мен ғалымға арналған жұмыс кеңістігі (2026-11-04)

## Мақсат (неге)
ecojaiyq.com қазір көрсетеді, бірақ жұмыс істеуге мүмкіндік бермейді. Әкімдік/инспектор
мен ғалым картада **әрекет жасай** алуы керек: аймақ бойынша нақты сан алу, далада
істелген жұмысты тіркеу, спутник тапқанды растау/жоққа шығару, «ластану қайдан
келді» деген сұраққа жауап алу. Үлгілер: Global Forest Watch (аймақ → статистика),
EMSA CleanSeaNet (детекция → мемлекет тексеруі → кері байланыс), FieldSeeker
(маса бақылау далалық журналы), i-Tree Landscape / Tree Equity Score (салмақты
басымдық картасы), EPA HYSPLIT (кері траектория).

## Ортақ құралдар (барлық қабат)
1. **Аймақ есебі** — полигон сызу (бар құрал) немесе GeoJSON/KML жүктеу →
   метрика: NDVI (Sentinel-2 L2A, SCL бұлт маскасы, айлық), NO₂ тропосфералық баған
   (Sentinel-5P, айлық), жылу аномалиялары (FIRMS VIIRS, айлық, алау/расталмаған),
   жер пайдалану мен табиғат қиылысы (OSM статикалық көшірмесі, Ақжайық OSM rel).
   Нәтиже: кесте + график + CSV (рөл) + GeoJSON полигон.
   Шектеу: аудан ≤ 2 000 км², ≤ 500 төбе, Атырау облысы шегінде.
2. **Далалық журнал** (`field_entries`) — нүкте/полигон + қабат + әрекет түрі +
   өрістер (JSON, қабатқа сай схема) + мәртебе + тарих. Түрлер:
   көгалдандыру: отырғызу (түр, саны, күні, мәртебе жоспар→отырғызылды→тамыр алды/қурады);
   қоқыс: үйінді (көлем, түрі) → тазаланды; маса: көбею орны, личинкаға қарсы өңдеу
   (препарат, мөлшер), тұзақ (саны); ауа/су/топырақ/мұнай: сынама (параметр, мән,
   бірлік, зертхана); табиғат: бақылау; жалпы: инспекция.
   Көгалдандыру тексеруі: отырғызу полигоны үшін отырғызуға дейінгі жаз vs соңғы жаз
   NDVI (сол Sentinel-2 құбыры). Бұл «ағаш өсті» дегенді дәлелдемейді — ескерту.
3. **Детекцияны растау** (`detection_reviews`) — CleanSeaNet үлгісі: FIRMS аномалиясы,
   мұнай дағы (oil-scan), NO₂ шыңы, шағым үшін: расталды / жалған / тексерілмеді +
   ескерту. Шешім мен күні жария, тексерушінің ID-і жария емес.
4. **Аймаққа жазылу** (`watch_areas`) — полигон + қабаттар; күнделікті cron FIRMS
   жаңа аномалияларын тексереді → `watch_events`; сайтта «Менің аймақтарым».
   (Telegram хабарламасы — кейін.)
5. **Басымдық картасы** — қала торы (~1 км), критерийлер: NDVI тапшылығы (Sentinel-2),
   тұрғын үй үлесі (OSM — халық тығыздығының ПРОКСИ-і, белгіленеді), өнеркәсіп
   көзіне жақындық (тізілім). Салмақтарды пайдаланушы жылжытады. 📊 модель.

## Қабатқа арнайы
- Ауа: **кері траектория** — нүкте → Open-Meteo сағаттық 10 м жел бойынша 1–24 сағат
  кері; маршрут бойындағы тізілім көздері. 📊; HYSPLIT емес (тік қозғалыс,
  турбуленттілік жоқ) — ескерту.
- Табиғат/жер пайдалану: полигонның Ақжайықпен, OSM жасыл/су/өнеркәсіппен қиылысуы (№1).
- Өрт, мұнай: №3 растау. Қоқыс, маса, көгалдандыру: №2 журнал.
- Құрғақшылық/топырақ/жел: №1 (нүкте/центроид қатарлары кейін).

## Кезеңдер
A. Аймақ есебі (NDVI, NO₂, FIRMS, OSM/табиғат) + жүктеу/экспорт.
B. Далалық журнал + көгалдандыру NDVI тексеруі.
C. Детекцияны растау.
D. Кері траектория.
E. Аймаққа жазылу.
F. Басымдық картасы.
