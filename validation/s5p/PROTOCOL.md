# Валидация №2б — АМӨЗ үстіндегі NO₂ / SO₂ (Sentinel-5P TROPOMI)

> **Алдын ала тіркелген хаттама.** 2026-11-02, S5P деректері жүктелмей
> тұрып жазылды. Шектер нәтижеге қарап өзгертілмейді.
> Тек ЖАРИЯ дереккөздер: Copernicus Sentinel-5P L2 (CDSE), ERA5 жел
> (Open-Meteo archive), OpenStreetMap.

## 1. Сұрақ

Jaiyq «ластану көзі» модулі (`lib/pollutionSource.ts`) АМӨЗ-ді NO₂ мен
SO₂ көзі ретінде көрсетеді. Тәуелсіз спутник бұл нысанның үстінде
**желдің бағытына сәйкес** артық NO₂/SO₂ көре ме?

- **H3 (NO₂).** Желдің ығындағы (downwind) сектордағы тропосфералық NO₂
  жел жақтағы (upwind) сектордан жүйелі түрде жоғары.
- **H4 (SO₂, зерттеу).** Дәл сол тест SO₂ үшін. TROPOMI SO₂ шуы жоғары,
  шағын көздерді жиі көрмейді — сондықтан H4 «зерттеу» деп белгіленеді;
  теріс нәтиже «көз жоқ» дегенді БІЛДІРМЕЙДІ.

## 2. Деректер

| | |
|---|---|
| Өнім | Sentinel-5P L2 NO2 (`tropospheric_NO2_column_number_density`), L2 SO2 (`SO2_column_number_density`) |
| Сапа | NO₂: `qa_value ≥ 0.75`; SO₂: `qa_value ≥ 0.5` (ESA PRF ұсынымдары) |
| Кезең | 2024-01-01 … 2026-10-31 |
| Жел | ERA5 10 м жел, S5P өту сағатына жақын 09:00 UTC (Open-Meteo archive), АМӨЗ нүктесінде |
| Орталық | АМӨЗ OSM контурының центроиді |
| Қол жеткізу | Sentinel Hub Statistical API (CDSE), күн сайынғы орташа |

## 3. Әдіс (бекітілген)

- Орталықтан **5–20 км** сақина, сегіз **45°** секторға бөлінеді.
- Әр күні ERA5 желінің бағыты бойынша: **downwind** = жел соғатын
  жақтағы сектор, **upwind** = қарама-қарсы сектор.
- Күн жарамды: жел жылдамдығы **≥ 2 м/с** (әйтпесе сектор мағынасыз),
  екі секторда да жарамды пиксель бар.
- Статистика: Δ = NO₂(downwind) − NO₂(upwind) күн сайын; орташа Δ мен
  **апталық блоктық бутстреп** (10 000 рет) арқылы 95% сенім аралығы.
- Сезімталдық (pass/fail-ге кірмейді): 0–5 км орталық диск vs upwind;
  маусым бойынша бөлу.

## 4. Шектер

| | Шарт |
|---|---|
| **H3 өтті** | орташа Δ > 0 және 95% СА төменгі шегі > 0, жарамды күн ≥ 100 |
| **H4 өтті** | сол шарт SO₂ үшін |

## 5. Шектеулер (алдын ала мойындалған)

- TROPOMI пикселі ≈ 3.5 × 5.5 км. **АМӨЗ пен ЖЭО шекаралас** —
  оларды ажырату мүмкін емес. Тест «АМӨЗ+ЖЭО өнеркәсіп тобының»
  сигналын тексереді.
- Қала NO₂-сі де сектор айырмасына кіреді: қала АМӨЗ-ден солтүстік-
  батыста. Сондықтан нәтиже маусым/жел бағыты бойынша бөлек беріледі.
- Бұл шығарынды мөлшерін (т/жыл) бағаламайды — тек сигналдың барын.

## 6. Толықтыру v1.1 — басқа нысандар (2026-11-04, деректер жүктелмей тұрып)

Дәл сол әдіс, шектер мен параметрлер (§2–§4) тізілімдегі басқа нысандарға
қолданылады: **КПИ** (`kpi`), **Болашақ** (`bolashak`), **Теңіз** (`tco`).
Скрипт: `validate_s5p_facilities.py` (бұрынғы скрипттің функцияларын
өзгертпей қолданады), нәтиже: `results_facilities.json`.

- **Орталық:** нысанның OSM контурларының ауданмен өлшенген центроиді
  (`src/data/facilities.ts` → `footprint`). Жел — сол нүктедегі ERA5.
- **ЖЭО** (`tets`) АМӨЗ-ден ~1.7 км, яғни АМӨЗ-дің 0–5 км орталық дискісінде
  жатыр → бөлек тестілеу мағынасыз; ол АМӨЗ нәтижесімен бір «кластер».
- **Көрші көз:** сақинада (5–20 км) тізілімдегі басқа нысан болса,
  нәтижеде `neighbours_in_ring` деп белгіленеді. КПИ мен Болашақ бір-бірінен
  ~18 км, сондықтан бір-бірінің сақинасына түседі — сигналды біреуіне ғана
  телуге болмайды.
- **Түсіндіру:** өтпеген тест «шығарынды жоқ» дегенді білдірмейді (шағын көз
  TROPOMI сезімталдығынан төмен болуы мүмкін). Өткен тест — тек ығындағы
  артық сигналдың барын көрсетеді, мөлшерін (т/жыл) емес.
